Visual Analytics, Scatter Plots & Model Curves

Multi-perspective graphical analysis demonstrating feature interactions, probability curves, and diagnostic accuracy.

Scatter Plot: Patient Age vs. Serum Cholesterol

This bi-variate scatter plot visualizes patient distribution across chronological age (30–79 years) and serum cholesterol (150–299 mg/dL). Each point represents an individual patient, colored by diagnostic status (Red: Heart Disease = 1; Blue: Healthy = 0).

Exploratory Objective: Identify non-linear clustering and density boundaries across age cohorts.

Clinical takeaway: Older cohorts combined with cholesterol levels above 220 mg/dL demonstrate higher frequencies of cardiovascular disease events.

Scatter Plot: Blood Pressure vs. Body Mass Index

Examines hemodynamic stress (resting blood pressure in mmHg) against anthropometric obesity index (BMI in kg/m²). Permits inspection of how hypertensive stages (Stage 1: 130–139, Stage 2: ≥140 mmHg) compound with obesity categories (BMI ≥ 30).

Hypothesis: Synergistic interaction between vascular pressure and metabolic excess elevates disease probability.

Patients in the upper-right quadrant (BP > 140 mmHg & BMI > 30) exhibit concentrated positive diagnosis likelihood.

Logistic Regression Probability Sigmoid Function

Displays the core mathematical mapping that converts linear log-odds composite risk scores ($z$) into calibrated disease probabilities between 0% and 100%.

P(Y=1|X) = σ(z) = 1 / (1 + e^(-z))
where z = β₀ + β₁X₁ + β₂X₂ + ... + β₁₀X₁₀

The decision threshold sits at $p = 0.5$ ($z = 0$). Test set patients are overlaid to illustrate actual binary outcomes versus model predicted likelihood.

Confusion Matrix Heatmap (80/20 Test Set)

Quantifies exact diagnostic classifications across the 100 held-out test patients:

  • True Positives (TP = {{ tp }}): Sick patients correctly diagnosed.
  • True Negatives (TN = {{ tn }}): Healthy patients correctly diagnosed.
  • False Positives (FP = {{ fp }}): Healthy patients flagged (Type I error).
  • False Negatives (FN = {{ fn }}): Missed sick patients (Type II error).
